# Heft

Notizen mit Markdown, Sofortsuche und „Seite merken“. Für Quetta, Chrome und Edge.

## Download

- [heft-quetta.crx](https://github.com/b3taisadonna/heft/releases/download/v1.0.0/heft-quetta.crx) für Quetta auf dem Handy
- [heft-quetta.zip](https://github.com/b3taisadonna/heft/releases/download/v1.0.0/heft-quetta.zip) für den Computer

Dieselben Dateien liegen auch im Repository: `heft-quetta.crx` und `heft-quetta.zip`.

## In Quetta installieren

1. Die CRX-Datei herunterladen.
2. Quetta öffnen und `chrome://extensions` eingeben.
3. Entwicklermodus einschalten, falls der Schalter da ist.
4. Die CRX aus der Dateien-App im geteilten Fenster auf die Erweiterungsseite ziehen.
5. Auf Hinzufügen tippen. Heft liegt danach im Menü unter Erweiterungen.

## Am Computer

1. Die ZIP entpacken.
2. `chrome://extensions` öffnen und den Entwicklermodus einschalten.
3. „Entpackte Erweiterung laden“ wählen und den Ordner öffnen.

Notizen bleiben in diesem Browser (`chrome.storage` bzw. lokal).
